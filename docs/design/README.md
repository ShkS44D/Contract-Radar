# Report design reference

`report-concept.png` was generated with the built-in Image Gen tool as a visual reference, not executable UI. Prompt: a full 1536x1024 desktop Solidity Sentinel report with charcoal/emerald colors, header, score/grade/risk band, compiler/engine/duration/SLOC/contract/function metadata, severity filters and search, expandable evidence/remediation/source findings, exports, and audit disclaimer. No gradients, decorative badges, sidebar, marketing imagery, or external assets.

Implementation tokens: background #0b1010, surface #101819, foreground #f4f7f6, muted #a7b8c1, border #344548, accent #4ade80, high #ff6b76, medium #fbc34b. System sans-serif and monospace; 42px heading, 26px section headings, 16px body, 14px controls; 7-8px component radii. Preserve the concept's open horizontal report layout and two-column expanded finding, collapsing to one column on mobile.

The generated reference's example rule IDs/severities are illustrative and sometimes inconsistent. Real reports use the tested detector registry. Other intentional differences: dynamic findings may change row count/text/height; the required scoring breakdown and engine warnings extend the page; the original red shield favicon remains intact. Upload, loading, and error states use this same design system, with functional instructions required for those workflows.

Verification ledger (2026-10-12): in-app browser attach timed out; Playwright Chromium fallback exercised a real upload, loading/polling, completed report, filters, search, disclosure, PDF download, and broken-source error. Checked desktop 1536x1024 (concept native size) and mobile 390x844, no horizontal overflow or JS exceptions. `view_image` inspection compared the reference and rendered report for header alignment, horizontal metadata band, charcoal/emerald palette, control row, split evidence/code body, and responsive collapse. Dynamic content is intentional; no new decorative copy was added. Windows CRLF line expansion and less-readable duplicate Slither wording were repaired. Required scoring disclosure is an intentional addition below findings. Rendered PDF pages were inspected; finding groups are kept together to avoid splitting code context unnecessarily.

Final pass after repository cleanup: the reference and fresh TxOrigin report at both sizes were re-inspected. Header/container alignment, palette, system typography, filter/export controls, split description/source layout, and mobile stacking match the reference's design system. Above-the-fold copy uses the requested branding/workflow plus required real metadata; the reference's sample finding counts/text/IDs remain illustrative. Source code uses escaped monospace text and highlighted evidence lines rather than extra raster/syntax-color assets. Remaining differences are intentional dynamic data, inherited favicon color, and required warnings/scoring disclosure. No material layout/interaction defect remained in the checked flows.
