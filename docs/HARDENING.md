# Input and deployment policy

Defaults: 2 MiB HTTP request and per-source limit, 8 MiB total expanded sources, 50 source files, at most 100 ZIP entries, compression ratio <=100, nesting <=10, relative path <=240 characters. Only Solidity files/directories are accepted in ZIPs. Symlinks/special files, encrypted archives, duplicate case-folded names, traversal/absolute/drive/UNC paths, Windows reserved names, binary control bytes, malformed UTF-8, empty files, and unrecognizable source text are rejected. Expanded bytes are counted while reading, not trusted solely from ZIP headers. Archive build scripts are never accepted or executed.

Uploads live under a private UUID root. Single files have random physical names; logical result locations use the submitted basename. `finally` cleanup runs after all engine states, queue rejection, or job exceptions. A single-process lock prevents two app instances from recovering one another's jobs. On restart, abandoned UUID temporary directories are removed only after resolving their parent against the expected source root.

Flask-WTF protects browser POSTs. The unauthenticated multipart API is CSRF-exempt for non-cookie clients but rejects foreign Origin/cross-site browser fetches; no CORS allowance is sent. Both scan entry points share a configurable per-client rate limit. Admission is separately bounded by the worker/queue capacity. Client addresses use Flask's direct remote address; no arbitrary proxy headers are trusted. Configure trusted proxy handling deliberately if deploying behind a proxy.

Responses use a strict self-only CSP, no framing, nosniff, same-origin referrers, disabled camera/microphone/geolocation, and no-store for dynamic responses. Same-origin referrers preserve HTTPS CSRF validation while external links receive no referrer. HSTS is emitted for HTTPS requests. Set secure cookies when serving over HTTPS. Production requires a long configured secret and disables debug mode. Unexpected errors return sanitized messages and log server-side details.

SQLite stores normalized reports/snippets, not complete sources. Retention defaults to 24 hours from submission and is preserved on status updates. Cleanup runs on lookup and once per minute while the service is running. Secure-delete is enabled for SQLite pages; filesystem/volume backups and OS-level recovery are outside this logical retention policy. UUID report URLs are bearer access, not authentication. Keep links private.

Scanner children receive a small runtime environment without application secrets. Each process group has a whole-scan timeout and bounded stdout/stderr. Docker adds non-root execution, read-only root filesystem, restricted writable mounts, dropped capabilities, no-new-privileges, and resource limits. Compiler downloads still require outbound connectivity unless using the preinstalled versions in offline mode. The compiler cache is named `.solc-select`; the app translates configured cache location to solc-select 1.2's VIRTUAL_ENV-based layout.

This is designed as a local/small-team tool. Do not expose it as a public multi-tenant service without authentication, stronger sandbox isolation/network controls, trusted proxy configuration, durable distributed workers, and storage quotas. A non-root container is not a guarantee against compiler/engine vulnerabilities.
